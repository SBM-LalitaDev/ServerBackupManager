Funcionalidades

Todo lo necesario para proteger tus configuraciones

Una herramienta práctica para mantener respaldada la información importante de tus servicios Render.

☁️

Múltiples cuentas Render

Agregá varias cuentas mediante sus API Keys y administrá sus respaldos desde una misma aplicación.

📋

Variables de entorno

Respalda las variables de entorno de los servicios y Environment Groups de tus cuentas.

📁

Secret Files

Incluye los archivos secretos de servicios y Environment Groups, conservando sus nombres y contenidos.

🔐

Cifrado avanzado

Cada respaldo se protege mediante AES-256-GCM y una clave derivada con scrypt.

🔄

Restauración de backups

Recuperá los datos de un respaldo cifrado y generá los archivos correspondientes en una carpeta de destino.

💻

Aplicación de escritorio

Interfaz sencilla para Windows, sin necesidad de utilizar comandos manualmente para las operaciones habituales.

Fácil de utilizar

¿Cómo funciona?

Realizá tus respaldos en pocos pasos, sin complicaciones.

01

Conectá tu cuenta

Ingresá un nombre y la API Key de tu cuenta Render. Podés agregar varias cuentas.

02

Creá el respaldo

Elegí una carpeta de destino y una contraseña para proteger el backup.

03

Guardá tu backup

La aplicación genera archivos .hcbackup cifrados para conservarlos de forma segura.

04

Restaurá cuando quieras

Seleccioná un backup, ingresá su contraseña y recuperá los archivos.

Privacidad y protección

La seguridad de tus datos es una prioridad.

Los respaldos contienen información sensible. Por eso, Server Backup Manager utiliza un sistema de cifrado para proteger su contenido.

Las API Keys permanecen en memoria durante la sesión y no se guardan en archivos de configuración de la aplicación.

✓
AES-256-GCM Cifrado autenticado de los respaldos.
✓
Derivación de claves con scrypt Protección mediante una contraseña elegida por el usuario.
✓
Credenciales temporales Las API Keys no se persisten en la aplicación.
✓
Almacenamiento local Los backups se guardan en la ubicación elegida por el usuario.

  • Windows 10 u 11.
  • Python 3.10 o superior, instalado desde python.org y agregado al PATH.
  • Conexión a Internet para consultar la API de Render.

⚠️ Alcance actual del respaldo

Actualmente, Server Backup Manager permite respaldar variables de entorno y Secret Files de servicios y Environment Groups de Render. No incluye bases de datos, discos persistentes, DNS, dominios ni configuraciones de despliegue. La restauración genera archivos locales para facilitar la recuperación manual de la información; no modifica automáticamente la configuración de los servicios en Render.
